# Package Index

Start with `README_FIRST.md`. The files under `docs/` are the complete product and engineering requirements. Machine-readable contracts are under `schemas/`; Switch configuration and role prompts are under `switch/` and `agents/`; synthetic seed data is under `fixtures/`.

**Important:** API paths and SQL schema are a proposed InvoiceOps implementation contract, not Switch API routes. The Switch template is a blueprint derived from the public challenge template format and must be validated in the current Switch Console before use.
